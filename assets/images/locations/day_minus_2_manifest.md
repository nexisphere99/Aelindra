# Day -2   Location Images

Wired up in code already (`day-2_hub.tw`, the sub-hub passages, and each main
scene's `.scene-image` banner via the `<<locationImage>>` widget)   the game
runs fine without these files (they fail silently, see `src/ui/script.js` /
`src/ui/widgets.tw`), but drop a same-named `.png`/`.jpg` (as `.png`, per the
widget) into this folder and it'll appear automatically, no code changes
needed.
